Opponent hands — collapse signifier mockup

Every frame below is a real 375px phone viewport running css/play.css, so the mobile media queries fire the same way they do on a handset. In each phone the top zone starts expanded and the lower two collapsed — the real mobile default. Tap any header to toggle. Today the chevron ships as rgba(233,224,198,.5) on #e9e0c6: identical RGB, contrast 1.00:1, invisible.

2. Live phones — tap the headers

Same three opponents, same data, three treatments.

A. Button chrome + nudge

Chevron recoloured to ink and wrapped in a bordered pill, so it reads as pressable without hover. Bounces twice on first render — the one discovery cue that survives on touch.

No width cost; header stays one line.

B. Peek strip

Collapsed state keeps a ~24px sliver of the hand under a fade. The cut-off edge is itself the “more below” cue, and the collapsed state becomes informative instead of blank.

Costs height on the screen with least to spare.

C. Native <details>

A real disclosure widget: keyboard-operable and announced as expanded/collapsed to screen readers. Both are absent today — the header is a bare div with an onclick.

Loses the 0.25s ease — <details> snaps open and shut.
